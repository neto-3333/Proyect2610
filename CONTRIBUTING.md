# Contribuir a Serie Clara

Puedes ayudar reportando errores, mejorando explicaciones o proponiendo casos de uso.

Para un error, incluye pasos, resultado esperado, versión de Python y un CSV sintético mínimo. No publiques datos bancarios, personales ni confidenciales.

Para cambios de código: instala `requirements.txt`, añade una prueba que demuestre el comportamiento y ejecuta `python -m pytest -q`. Los cambios estadísticos deben explicar supuestos, límites y evitar uso de observaciones futuras en entrenamiento. Las correcciones de datos deben ser opcionales y auditables.

Para cambios grandes, describe antes el problema y la propuesta en una incidencia del repositorio. Las contribuciones al código se realizan bajo la licencia MIT del proyecto.
